# Assets

Asset areas:

- `art/` - miner, mine, treasure, pyrite and environmental artwork
- `audio/` - sound effects and music if later used
- `fonts/` - only redistributable fonts with documented licences
- `ui/` - icons and interface artwork

Every asset must have known provenance and a redistribution/modification licence compatible with the project. Keep attribution information alongside the asset set or in a future asset manifest.

# GitHub Repository Setup

## Suggested repository description

> Windows solo miner for Safex Cash with simple setup, mining profiles, MSR optimisation and state-driven visual feedback.

Alternative shorter version:

> Easy-to-use Windows solo miner for Safex Cash.

## Suggested topics

Use only topics that accurately describe the repository.

Possible topics:

```text
safex
safex-cash
sfx
mining
solo-mining
xmrig
windows
desktop-app
cpu-mining
cryptocurrency
```

Add framework/language topics once the implementation stack is final and visible in the repository.

## README image strategy

Once the app has a polished working screen, the README should include:

1. one hero screenshot of the main MINING state;
2. a smaller strip or gallery showing:
   - seated/ready;
   - block found;
   - rejected.

Do not lead the README with unfinished concept art once working UI screenshots exist.

## Suggested About-panel website

Only add a project website if one actually exists and is maintained.

Do not point to an unrelated Safex site as though it were the application's homepage.

## Releases

Each public release should include:

- Windows installer;
- version number;
- concise changelog;
- checksum;
- known issues if relevant;
- third-party notices/licences.

## Discussions

If GitHub Discussions is enabled, useful categories might be:

## Security

Before public release, add a security/contact policy appropriate to the project's actual support capacity.

Do not promise response times that cannot be maintained.

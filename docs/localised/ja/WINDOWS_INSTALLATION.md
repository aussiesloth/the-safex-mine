# The Safex Mine — Windows へのインストールと初回使用

> **コミュニティ翻訳。** このページは、重要なインストールおよびセキュリティ手順を AI 支援で翻訳したプロジェクト文書です。[英語版インストールガイド](../../WINDOWS_INSTALLATION.md)が正式な参照文書です。用語や表現の修正提案を歓迎します。

## 1. 公式リリースからのみダウンロード

The Safex Mine は、CPU マイナー、昇格権限で動作するヘルパー、WinRing ドライバーを含む**未署名**の Windows x64 アプリです。インストーラーはプロジェクトの公式 GitHub リリース からのみダウンロードしてください。

## 2. **実行前に** SHA-256 を確認

PowerShell で次を実行します。

    Get-FileHash .\The-Safex-Mine_<version>_x64-setup.exe -Algorithm SHA256

表示された値を、GitHub リリース に掲載された SHA-256 と正確に比較してください。

**Microsoft Defender がダウンロード直後にインストーラーを隔離した場合:** まず**そのダウンロードしたインストーラーだけ**を復元/許可し、その後 SHA-256 を計算してください。公式値と一致するまでは実行しないでください。

## 3. SmartScreen とウイルス対策

未署名であり、マイニング関連コンポーネントを含むため、SmartScreen やセキュリティ製品が警告または隔離を行う場合があります。配布元とハッシュを確認してから進めてください。

ウイルス対策を広範囲に無効化しないでください。Downloads、ユーザープロファイル全体、ドライブ全体を除外しないでください。検証後に除外が本当に必要な場合は、次のフォルダーだけに限定してください。

    %LOCALAPPDATA%\The Safex Mine

## 4. インストール、言語、リスク確認

NSIS インストーラーは通常、Windows の表示言語に基づいて日本語を自動選択します。アプリの言語は起動後にも変更できます。

初回起動時には、選択した対応アプリ言語で **マイニングリスク確認書 — v1.0** が表示されます。続行前に内容を確認してください。**終了** を選ぶと同意を保存せず終了します。英語版が正式な参照です：[マイニングリスク確認書 v1.0](../../MINING_RISK_ACKNOWLEDGEMENT.md)。

## 5. UAC ヘルパーと MSR

GUI 自体は通常ユーザー権限で動作します。1 回のアプリセッションで最初に **マイニング開始** を押すと、Windows は次のヘルパーについて UAC 承認を求めます。

    safex-mine-helper.exe

昇格されるのはこのヘルパーだけです。XMRig の起動・監視と MSR 最適化の試行を担当します。Windows のセキュリティ機能が MSR をブロックした場合も、性能を下げて採掘を継続できます。ハッシュレート向上だけを目的にセキュリティ機能を無効化しないでください。

## 6. アンインストール

アンインストールでアプリは削除されます。手動で追加した Defender 除外は残る場合があるため、不要なら後で手動削除してください。

# The Safex Mine — Windows इंस्टॉलेशन और पहली बार उपयोग

> **सामुदायिक अनुवाद।** यह पृष्ठ आवश्यक Windows इंस्टॉलेशन, सुरक्षा और पहली बार उपयोग संबंधी निर्देशों का AI-सहायता प्राप्त परियोजना अनुवाद है। [अंग्रेज़ी इंस्टॉलेशन गाइड](../../WINDOWS_INSTALLATION.md) परियोजना का मूल संदर्भ बना रहता है। भाषा और शब्दावली सुधारों का स्वागत है।

## 1. केवल आधिकारिक रिलीज़ से डाउनलोड करें

The Safex Mine एक **बिना डिजिटल हस्ताक्षर वाला** Windows x64 एप्लिकेशन है जिसमें CPU माइनर, उन्नत-अधिकार सहायक और WinRing ड्राइवर शामिल हैं। इंस्टॉलर केवल परियोजना की आधिकारिक GitHub रिलीज़ से डाउनलोड करें।

## 2. चलाने से **पहले** SHA-256 सत्यापित करें

PowerShell में:

    Get-FileHash .\The-Safex-Mine_<version>_x64-setup.exe -Algorithm SHA256

परिणाम को रिलीज़ के साथ प्रकाशित SHA-256 से ध्यानपूर्वक मिलाएँ।

**यदि Microsoft Defender डाउनलोड के तुरंत बाद इंस्टॉलर को क्वारंटीन कर देता है:** पहले **उसी विशेष डाउनलोड किए गए इंस्टॉलर को ही** पुनर्स्थापित या अनुमति दें, फिर उसका SHA-256 निकालें और जब तक हैश आधिकारिक मान से मेल न खाए, उसे **न चलाएँ**।

## 3. SmartScreen और एंटीवायरस

रिलीज़ बिना डिजिटल हस्ताक्षर की है और उसमें माइनिंग घटक शामिल हैं, इसलिए SmartScreen या अन्य सुरक्षा सॉफ़्टवेयर चेतावनी दे सकता है या फ़ाइलों को क्वारंटीन कर सकता है। स्रोत और हैश सत्यापित करने के बाद ही आगे बढ़ें।

एंटीवायरस को व्यापक रूप से बंद न करें। Downloads फ़ोल्डर, पूरा उपयोगकर्ता प्रोफ़ाइल या पूरी ड्राइव को अपवाद में न डालें। यदि रिलीज़ सत्यापित करने के बाद वास्तव में अपवाद आवश्यक हो, तो इसे केवल यहाँ तक सीमित रखें:

    %LOCALAPPDATA%\The Safex Mine

## 4. इंस्टॉलेशन, भाषा और जोखिम सूचना

NSIS इंस्टॉलर सामान्यतः Windows की प्रदर्शन भाषा के आधार पर हिन्दी चुनता है। ऐप शुरू होने के बाद एप्लिकेशन की भाषा बदली जा सकती है।

पहली बार चलाने पर चुनी गई समर्थित भाषा में **माइनिंग जोखिम स्वीकृति-पत्र — संस्करण 1.0** दिखाया जाता है। आगे बढ़ने से पहले इसे पढ़ें। **बाहर निकलें** चुनने पर स्वीकृति सहेजे बिना ऐप बंद हो जाता है। अंग्रेज़ी मूल संदर्भ है: [माइनिंग जोखिम स्वीकृति-पत्र v1.0](../../MINING_RISK_ACKNOWLEDGEMENT.md).

## 5. UAC सहायक और MSR

ग्राफ़िकल ऐप सामान्य उपयोगकर्ता के रूप में चलता है। किसी सत्र में पहली बार **माइनिंग शुरू करें** चुनने पर Windows इस फ़ाइल के लिए UAC स्वीकृति माँगता है:

    safex-mine-helper.exe

केवल इसी सहायक को उन्नत अधिकार मिलते हैं। यह XMRig को शुरू और नियंत्रित करता है तथा MSR अनुकूलन का प्रयास संभव बनाता है। यदि Windows सुरक्षा व्यवस्था MSR को रोकती है, तो माइनिंग कम प्रदर्शन के साथ जारी रह सकती है। केवल अधिक हैशरेट पाने के लिए Windows की सुरक्षा सुविधाएँ बंद न करें।

## 6. अनइंस्टॉल

अनइंस्टॉल करने से एप्लिकेशन हट जाता है। आपके द्वारा हाथ से जोड़ा गया Defender अपवाद रह सकता है; आवश्यकता न रहने पर उसे बाद में स्वयं हटा दें।

अधिक सहायता: [अंग्रेज़ी समस्या निवारण](../../../TROUBLESHOOTING.md).

# The Safex Mine — Установка в Windows и первый запуск

> **Перевод сообщества.** Эта страница — подготовленный с помощью ИИ проектный перевод основных инструкций по установке и безопасности. [Английское руководство по установке](../../WINDOWS_INSTALLATION.md) остаётся каноническим источником проекта. Языковые и терминологические исправления приветствуются.

## 1. Скачивайте только из официального релиза

The Safex Mine — **неподписанное** приложение Windows x64, включающее CPU-майнер, помощник с повышенными правами и драйвер WinRing. Скачивайте установщик только из официального релиза проекта на GitHub.

## 2. Проверяйте SHA-256 **до запуска**

В PowerShell:

    Get-FileHash .\The-Safex-Mine_<version>_x64-setup.exe -Algorithm SHA256

Точно сравните результат с SHA-256, опубликованным вместе с релизом.

**Если Microsoft Defender сразу после загрузки помещает установщик в карантин:** сначала восстановите/разрешите **только этот конкретный скачанный установщик**, затем вычислите его SHA-256 и **не запускайте**, пока хэш не совпадёт с официальным значением.

## 3. SmartScreen и антивирус

Поскольку релиз не подписан и содержит компоненты майнинга, SmartScreen или другие средства защиты могут показать предупреждение или поместить файлы в карантин. Продолжайте только после проверки источника и хэша.

Не отключайте антивирус полностью. Не добавляйте в исключения Downloads, весь профиль пользователя или целые диски. Если после проверки релиза исключение действительно требуется, ограничьте его папкой:

    %LOCALAPPDATA%\The Safex Mine

## 4. Установка, язык и уведомление о рисках

Установщик NSIS обычно автоматически выбирает русский язык по языку интерфейса Windows. Язык приложения можно изменить после запуска.

При первом запуске на выбранном поддерживаемом языке приложения отображается **Mining Risk Acknowledgement — Version 1.0**. Прочитайте его перед продолжением. **Exit** закрывает приложение без сохранения согласия. Английский остаётся канонической ссылкой: [Mining Risk Acknowledgement v1.0](../../MINING_RISK_ACKNOWLEDGEMENT.md).

## 5. UAC-помощник и MSR

Графическое приложение работает от имени обычного пользователя. При первом **Start Mining** в сеансе Windows запрашивает подтверждение UAC для:

    safex-mine-helper.exe

Повышенные права получает только этот помощник. Он запускает и контролирует XMRig и позволяет попытаться применить оптимизацию MSR. Если защита Windows блокирует MSR, майнинг может продолжаться с меньшей производительностью. Не отключайте функции безопасности только ради более высокого хэшрейта.

## 6. Удаление

Удаление программы убирает приложение. Исключение Defender, добавленное вручную, может остаться; удалите его после деинсталляции, если оно больше не нужно.

Дополнительная помощь: [английское руководство по устранению неполадок](../../../TROUBLESHOOTING.md).
